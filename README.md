# Máy Hút Bụi (Vacuum Cleaner World)

Dự án mô phỏng robot hút bụi tự động tìm đường trên lưới ô vuông bằng nhiều thuật toán tìm kiếm trí tuệ nhân tạo.

## Cấu trúc dự án
* `main.py`: Điểm khởi chạy chương trình (giao diện Tkinter).
* `config.py`: Cấu hình bản đồ, vị trí xuất phát/mục tiêu.
* `node.py`: Cấu trúc dữ liệu Node và các hàm phụ trợ.
* `algorithms/`: Thư mục chứa các thuật toán tìm kiếm 
* `gui/`: Thư mục chứa giao diện Tkinter.
* `gif/`: Thư mục chứa các file GIF minh họa thuật toán.

## Cách chạy ứng dụng
Chạy lệnh sau tại thư mục gốc:
```bash
python main.py
```
